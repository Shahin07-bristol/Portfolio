Project 01

DIY RC Plane

Designed, built, and flight-tested an autonomous-grade remote-controlled aircraft from scratch. Integrated multidisciplinary systems including a custom 3D-printed landing gear, 3S electric propulsion, and multi-channel 2.4 GHz telemetry avionics within an optimized foamboard airframe.

Project
DIY RC Plane
Type
Personal Project
Date
March 2026

Component & Subsystem Breakdown

  • Power & Propulsion: Driven by a 2122 1400kV brushless outrunner motor paired with a 9050 propeller, controlled by a 40A Electronic Speed Controller (ESC). Powered by a 3S 2000mAh LiPo battery pack delivering high-discharge energy.
  • Radio Control & Electronics: Controlled using a FlySky FS-i6 6-channel 2.4 GHz transmitter paired with an FS-i6B receiver running on the AFHDS 2A protocol for a reliable, interference-free link. The receiver feeds signal to the servos and relays real-time battery voltage telemetry back to the transmitter screen.
  • Mechanics & Actuation: 9g micro servos configured to actuate control surfaces via precision pushrod linkages, converting rotational servo torque into linear control surface movement.
  • Landing Gear: Fixed 3D-printed landing gear featuring elastic tires for shock absorption during taxiing and landings, configured with a tricycle layout (two main wheels near the middle and one steerable/tail wheel at the bottom of the rudder).
  • Airframe & Aerodynamics: Fabricated the wing structure, fuselage, and empennage using lightweight 5mm foamboard. Designed the airfoil geometry and wing incidence angle to balance low stall speeds with stable glide characteristics under varying wind conditions.
  • Electrical Distribution & Safety: Engineered a secure, accessible power distribution layout featuring an XT60 main battery connector, clean wire routing and management, and a dedicated layout to prevent electromagnetic interference near the receiver.

Project Overview & Aerodynamic Target

Building a modular scale wind tunnel aimed at evaluating aerodynamic downforce, drag reduction, and flow behavior for the S-RC Cup ↗ competition.

  • S-RC Cup Context: The S-RC Cup ↗ is an engineering motorsport competition where students design, manufacture, and race radio-controlled cars, applying real-world engineering principles to optimize performance.
  • Hybrid Material Assembly: Planning a hybrid construction using 3D-printed structural ducting (contraction cone, diffuser, and fan housing) combined with laser-cut transparent acrylic side walls for full optical visibility.
  • Modularity & Future Upgrades: Structured to allow future additions, such as a load-cell balance system to measure lift and drag, as well as smoke injection for visual flow analysis.

Project 04

Avionics Gyroscope & HUD Flight Display

Engineered a real-time flight attitude telemetry system utilizing a Raspberry Pi Pico (RP2040) multi-core microcontroller and an MPU6050 IMU, streaming orientation data via serial communication to a custom Python/Pygame artificial horizon ground station display with audio stall/bank angle warnings.

Project
Flight HUD & Gyroscope
Type
Personal Project
Category
Avionics & Embedded Project
Tools
MicroPython, Pygame, CPython, Serial Comm

System Architecture & Subsystems

  • Dual-Core Microcontroller Logic: Programmed a Raspberry Pi Pico using MicroPython. Core 0 handles MPU6050 IMU readings, calculates pitch/roll with atan2, and streams serial data. Core 1 runs a dedicated worker thread to play 8-bit .wav warning audio files without interrupting telemetry loops.
  • Data Filtering: Implemented a simple exponential smoothing filter (α = 0.1) to reduce sensor noise in pitch and roll calculations.
  • Pygame Flight Display: Developed a desktop application using Pygame and PySerial to display a live artificial horizon with pitch ladder markings, bank angle indicators, and visual/audio alert banners.

Hardware & Component Specifications

Subsystem / Role Target Component Measured Parameter / Function
Processing Unit Raspberry Pi Pico (RP2040 Dual-Core) Dual-core multi-threading isolating sensor loop on Core 0 and background audio on Core 1.
Inertial Measurement (IMU) MPU6050 6-Axis Accelerometer & Gyroscope Configured custom SoftI2C pin mapping (SDA: Pin 16, SCL: Pin 17), extracting pitch/roll via atan2 with exponential filtering.
Audio Amplifier Circuit NPN Transistor Driver & Base Resistor Discrete hardware switching circuit protecting Pico GPIO while driving speaker audio pulses.
Audio Feedback Array PWM Audio Output + Speaker Driver Real-time Cockpit Voice Warnings (Stall, Bank Angle, Pull Up)
Ground Station Software Python (Pygame & PySerial) Real-time serial data stream processing and active artificial horizon HUD rendering with visual alerts.

Project 05

Ultrasonic Radar & Sweep Display

Engineered a mechatronic scanning radar using a Raspberry Pi Pico, servo motor, and ultrasonic sensor, streaming polar coordinate telemetry via serial communication to a custom Pygame radar display featuring trailing fade vectors and proximity threat alerts.

Project
Ultrasonic Radar Sweep
Type

Category

System Architecture & Subsystems

  • Scanning & Measurement Actuation: Programmed PWM control on the Raspberry Pi Pico to sweep a servo motor across 180° while simultaneously triggering an ultrasonic distance sensor to measure target range.
  • Non-Blocking Audio Feedback: Implemented a millisecond-tick timer (`time.ticks_ms`) to scale active buzzer beep frequencies dynamically based on object proximity without interrupting servo sweep timing.
  • Python Ground Station Radar: Developed a Pygame interface rendering polar grid lines, a real-time sweep needle, and a transparent alpha-blended decay trail for historical sector tracking.
